# hipCIM

hipCIM enables GPU accelerated image processing and computer vision operations for medical and life science images.
This library, built on top of ROCm™, enables the processing and analysis of multidimensional images used in life
sciences research and medical contexts.

hipCIM is currently in an Early Access state and is intended as a preview to the production ready release
planned for later this year.
